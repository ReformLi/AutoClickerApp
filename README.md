# Android自动点击器应用

这是一个仅限个人使用的Android悬浮式连点器应用，使用Kotlin语言开发，兼容Android Studio。

> 面向使用者的完整操作步骤与常见问题见 [user_guide.md](user_guide.md)。

---

## 1. 概述

这是一款基于 Android 无障碍服务的自动化工具，通过悬浮窗控制全局模拟点击、滑动和系统按键，支持多点顺序循环执行。应用内置**两种可切换的工作模式**（在主页分段开关切换并持久化，默认“连点器”）：

| 模式 | 对应服务 | 工作方式 |
| --- | --- | --- |
| 连点器（旧功能） | `FloatingWindowService` | 手动摆放编号点击点/滑动点，按顺序循环自动执行点击、滑动与系统按键 |
| 代点器（快捷点击） | `QuickClickService` | 为子按钮配置「目标文字」「模板图片」或「屏幕坐标」，点击时由无障碍服务定位（文本匹配 / 图像识别）或直接按坐标模拟点击，支持脚本保存/加载 |

主界面、悬浮窗与设置弹框使用 **Jetpack Compose**；代点器的全屏截图框选页、裁剪比例条与坐标拾取浮层使用原生 View（Service 浮层场景下窗口焦点与生命周期更可控）。原 XML 布局已移除，仅保留图标、颜色等基础资源。

> 代码目录、分包职责与关键约束见 [project_structure.md](project_structure.md)。

## 2. 系统权限要求

| 权限                           | 用途             |
| ---------------------------- | -------------- |
| `SYSTEM_ALERT_WINDOW`        | 显示全局悬浮窗        |
| `BIND_ACCESSIBILITY_SERVICE` | 模拟点击、滑动、全局按键   |
| `FOREGROUND_SERVICE`         | 保持后台运行，防止被系统杀死 |
| `FOREGROUND_SERVICE_DATA_SYNC` | 与两个服务声明的 `foregroundServiceType="dataSync"` 匹配（Android 14+ 必需） |
| `POST_NOTIFICATIONS`         | Android 13+ 显示前台服务通知（通知栏「停止」入口），运行时申请 |

> 无障碍服务必须由用户在系统设置中手动开启。
>
> ⚠️ **Android 14（API 34）起**：前台服务必须声明与 `foregroundServiceType` 对应的类型权限，否则 `startForeground()` 抛 `SecurityException`，表现为「点击启动悬浮窗后 App 闪退」。若要调整服务类型，需同步修改 `AndroidManifest.xml` 中的类型与类型权限。
>
> ⚠️ **Android 15（API 35）起**：`dataSync` 类型前台服务有 6 小时 / 24 小时运行时长上限，超时后系统回调 `Service.onTimeout()`，App 在几秒内主动停止服务（不会闪退），悬浮窗会随之消失。
>
> 代点器的「图像识别」依赖无障碍 `takeScreenshot`，**仅支持 Android 11（API 30）及以上**；低版本上截图捕获入口置灰、图像匹配点击不可用，文本匹配、坐标点击与连点器不受影响。
>
> 无障碍配置中已声明 `android:canTakeScreenshot="true"`。从旧版本升级后，如果图像识别提示截图失败，请在系统设置中**关闭再重新开启**本应用的无障碍服务，使新的能力声明生效。

## 3. 核心功能模块

### 3.1 悬浮窗主控制面板

**布局**：垂直排列的按钮组 + 一个主操作按钮。

**主按钮功能**：

- **点击**：展开/折叠下方操作按钮区域
- **按住拖动**：移动整个悬浮窗，松手后自动吸附到屏幕左边缘或右边缘

**操作按钮列表**（展开后显示）：

| 按钮    | 功能                         | 特殊行为                 |
| ----- | -------------------------- | -------------------- |
| 启动/停止 | 开始或停止连点循环，图标切换（播放/停止）      | 点击时若无无障碍服务或尚无点击点会弹出提示 |
| 添加    | 在屏幕中央创建一个新的编号点击点           | 仅非运行状态显示             |
| 减少    | 删除最后添加的点击点（若为滑动对则整个删除）     | 仅非运行状态显示             |
| 滑动    | 创建一对滑动起点（A）和终点（B），中间有管道连接  | 仅非运行状态显示             |
| 设置    | 打开全局设置对话框（循环次数、命名脚本管理）     | 仅非运行状态显示             |
| 透明度   | 打开「透明度」弹框，分别调节悬浮窗与点击 / 滑动点位的透明度（20%~100%）   | 仅非运行状态显示，与代点器各自独立保存 |
| 退出    | 关闭悬浮窗服务并通知主界面              | 仅非运行状态显示             |

**运行时行为**：

- 展开栏只保留主按钮与停止图标，其余按钮全部隐藏；主按钮仍可展开/折叠
- 点击停止按钮结束连点；点击悬浮窗上的空白区域也会立即停止（主按钮所在区域除外）
- 停止后完整按钮栏恢复，点击点重新可见、可拖动
- 运行中不再自动改变悬浮窗透明度，透明度完全由「透明度」弹框的设置决定
- 连点期间主按钮仍可拖动，松手后仍吸附左/右边缘

**透明度**：

- 「透明度」弹框内有两根滑块：「悬浮窗」（`root.alpha`）与「点击 / 滑动点位」（所有点位标记与滑动通道视图的 alpha）；滑块为统一的胶囊轨道 + 圆形滑钮样式（见 3.8 `AppSlider`）
- 按住滑块拖动时，弹框连同背后遮罩一起隐藏，只在**当前这根滑块原来的位置**叠一条 20% 不透明度的滑动进行条（轨道线、滑钮位置与滑块完全重合，显示当前百分比），滑钮始终在手指下方，方便直接观察真实透明度；松手后弹框恢复
- 「确定」持久化两个值，「取消」/返回键恢复打开前的值
- 连点器的两个值分别存于 `clicker_script_config.xml` 的 `window_alpha` 与 `point_alpha`，代点器只存 `window_alpha`，两边互不影响，仅弹框页面相同
- 运行中点击 / 滑动点位保持你设置的透明度正常显示，不再压到 30%；手势穿透改由 `FLAG_NOT_TOUCHABLE` 保证
- 运行中某个点位正在执行时，该点位（滑动时含起点、终点与通道）会短暂变为强调色（浅青 + 深色字），执行完恢复原样——用「变色」代替「消失」来提示这一步已执行
- 仅影响显示，不影响点位点击、拖动与手势穿透

### 3.2 点击点（普通按钮）

**创建**：点击“添加”按钮，屏幕中央生成一个 44dp 的品牌青圆角方块标记（14dp 圆角、渐变底 + 白色描边 + 柔和投影），数字外再套一圈细白环（靶心），显示编号。

**交互**：

- **按住拖动**：移动点击点到目标位置
- **长按（500ms）**：打开该点的设置对话框（全局悬浮窗样式）
- **短按**：无响应（仅用于定位）

**设置对话框内容**：

- 按钮名称（只读，显示当前编号）
- 类型选项（单选）：点击、双击、返回键、主页键、打开通知栏（滑动点仅显示“滑动”且不可修改）
- 点击位置（单选）：中间 / 随机
- 延迟（毫秒）— 完成本点所有重复后等待的时间
- 触摸时长（毫秒）— 点击/滑动持续时间，滑动类型下标签显示为“滑动持续时间”
- 重复次数 — 当前点连续执行的次数
- 随机距离（像素）— 点击位置在中心点周围随机偏移的范围
- 取消 / 保存按钮

**删除**：

- 点击“减少”按钮删除最后添加的点击点
- 若为滑动对，同时删除配对点及管道

**参数保存/加载**：

- 所有点击点参数（坐标、类型、延迟、触摸时长、重复次数、随机距离等）可在「悬浮窗设置」中保存为命名脚本
- 点击脚本名即可加载并恢复全部点位、管道与参数；已有未保存点位时会先确认覆盖

### 3.3 滑动点（管道连接的一对起点/终点）

**创建**：点击“滑动”按钮，屏幕中央生成一对 44dp 圆角方块标记（A1、B1，编号随 pair 递增）——起点为品牌青实心渐变（白字），终点为浅底描边态（浅青底 + 品牌色描边 + 深色字）；两点之间绘制一条品牌青通道（12dp 半透明轨带 + 2dp 实线中线），靠近终点处带白色 V 形箭头（深色描边保证浅色背景下也清晰），通道跟随两点移动。

**交互**：

- **按住拖动任意一端**：修改起点/终点坐标，管道实时拉伸/旋转，保持直线连接
- **长按 A1 或 B1**：打开该滑动对的设置对话框（统一设置起终点参数）
- 起点类型为“滑动起点”，终点为“滑动终点”，设置页面类型固定为“滑动”且不可更改

**管道特性**：

- 直线连接两个圆心，始终可见
- 两端按标记半径留白，通道不会压在起点 / 终点标记上
- 管道无触摸响应，仅作视觉指示
- 拖动节点时管道自动更新
- 滑动执行期间，整条通道切到强调色（浅青），执行完恢复品牌青

**删除**：

- 点击“减少”删除滑动对时，同时移除起点、终点视图及管道

### 3.4 连点执行逻辑

**启动连点**：

- 点击点与管道保持正常显示（沿用你设置的点位透明度），并添加 `FLAG_NOT_TOUCHABLE` 使手势穿透
- 按点击点 ID 升序循环执行所有点
- 支持总循环次数限制（可在全局设置中配置，0 表示无限）

**各类型动作实现**：

| 类型    | 执行方式                                          |
| ----- | --------------------------------------------- |
| 点击    | 在目标坐标（含随机偏移）执行触摸，时长由触摸时长决定，重复“重复次数”次，完成后等待延迟  |
| 双击    | 两次快速点击（间隔约 100ms），重复执行指定次数                    |
| 滑动    | 从起点中心坐标滑动到终点中心坐标，滑动持续时间由触摸时长控制，重复指定次数，完成后等待延迟 |
| 返回键   | 调用无障碍全局返回动作                                   |
| 主页键   | 调用无障碍全局主页动作                                   |
| 打开通知栏 | 调用无障碍全局打开通知栏动作                                |

**停止连点**：

- 手动点击停止按钮、点击悬浮窗空白区域、通知栏“停止”按钮或应用被划掉均会停止
- 停止后恢复完整按钮栏，恢复点击点的可触摸状态并清除执行态高亮（透明度沿用你的设置）

---

### 3.5 全局设置对话框

**入口**：点击悬浮窗“设置”按钮

**内容**：

- 总循环次数编辑框（0 或空表示无限循环）
- 「脚本」区：实心按钮「保存当前点位」+ 已保存脚本列表
  - 保存：输入脚本名（最多 12 个字符），同名先确认覆盖
  - 加载：点脚本名；当前有未保存点位时先确认覆盖，加载前自动停止连点
  - 改名：输入新名称，新名已存在时提示
  - 删除：红色确认框二次确认
  - 列表为空时显示「暂无已保存脚本」空状态
- 取消 / 确定（仅保存循环次数）

**行为**：

- 对话框为全局悬浮窗样式，居中显示，背景透明，圆角白色卡片（与全项目弹框共用 `AppDialogPanel` 统一外框）
- 脚本列表与代点器的脚本管理共用 `AppScriptList` 组件（行高 48dp、名称可点加载、右侧「改名 / 删除」）
- 点击卡片外部区域可关闭（不保存循环次数）

### 3.6 主界面（MainActivity）

**页面结构**（自上而下的分区式布局）：

| 区域 | 内容 |
| --- | --- |
| Hero 卡片 | 应用图标 + 应用名 + 「当前模式 · 模式说明」，品牌色底承载身份信息 |
| 权限与状态 | 标题行：左侧「权限与状态」+ 就绪徽标（已就绪 / 待授权），行尾是紧凑胶囊按钮「刷新」（与徽标同尺寸、品牌底色），点击重新检测权限与悬浮窗服务状态；下方卡片三行状态（悬浮窗权限 / 无障碍服务 / 悬浮窗运行），每行由状态圆点 + 名称 + 状态徽标组成，行间细分隔线 |
| 获取权限 | **仅在权限未齐备时出现**的实心按钮；权限齐备后由状态卡片说明一切，不再重复按钮 |
| 运行模式 | 标题行：左侧与「权限与状态」同款的分区标题，右侧为当前模式徽标（连点器 / 代点器）；下方紧贴连点器 / 代点器分段开关（间距 8dp，标题与控件成组），选择结果持久化；悬浮窗运行中禁止切换并提示先关闭 |
| 底部主操作 | 「启动 / 关闭悬浮窗」主按钮，平铺占满整行；未授权权限时禁用置灰，运行中为红色「关闭悬浮窗」 |

**视觉规则**：

- 页面底色用 `background`，卡片用 `surface` + 细描边（`outlineVariant`），靠亮度差而非阴影分层
- 状态用「圆点 + 徽标」表达，避免大块高饱和色块抢占注意力；正常态用中性徽标，成功态用成功色徽标
- 所有颜色 / 字号 / 圆角 / 间距均取自 `core/theme` 的设计 token，页面禁止硬编码

**全面屏适配**：

- `MainActivity` 调用 `enableEdgeToEdge()`，窗口铺满到状态栏 / 导航栏 / 刘海区域；页面底色继续铺满整屏，状态栏区域显示页面底色，与页面无缝
- 页面内容按 `WindowInsets.safeDrawing`（状态栏 + 导航栏 + 刘海）加内边距避让，内边距加在滚动容器之外：内容既不会被状态栏遮盖，也不会滚进系统栏区域
- 系统栏图标颜色随系统深浅色自动切换（浅色用深色图标、深色用浅色图标）

**广播监听**：

- 当悬浮窗服务被关闭时，收到 `SERVICE_STOPPED` 广播，自动更新界面按钮状态


### 3.7 代点器（悬浮快捷点击，QuickClickService）

主按钮有三种状态，**启动时只有主按钮（折叠态）**，单击主按钮展开 / 折叠；尚无子按钮时单击会直接进入编辑态，方便先添加按钮或加载脚本：

| 状态 | 显示内容 |
| --- | --- |
| 折叠态 | 仅主按钮 |
| 展开态 | 主按钮 + 已配置的子按钮（纵向排列） |
| 编辑态 | 主按钮 + `[+]` + 子按钮列表 + `[脚本管理]` + `[透明度]` + `[关闭]` |

**主按钮手势**（与连点器一致，屏幕绝对坐标、单一触摸状态机）：

- **单击**：展开 / 折叠（处于编辑态时单击为退出编辑、保留展开）
- **双击**：进入编辑态
- **按住拖动**：移动悬浮窗，松手吸附左 / 右边缘
- 无障碍服务未连接时，主按钮变灰（半透明）并提示重新开启

**子按钮**：

- 名称限长：含中文最多 2 字、纯英文/数字最多 3 字符；留空时默认「按钮N」
- **非编辑态点击**：按子按钮动作类型执行「文本匹配 → 定位 → 点击」「图像识别 → 匹配 → 点击」或「坐标点击」链路，命中后用 `dispatchGesture` 在目标坐标模拟点击（详见下方「动作类型」）
- **防抖**：同一按钮在间隔内（默认 500ms）不重复执行
- **自动收起**：可选「点击后自动收起悬浮窗」
- **编辑态点击子按钮**：打开「编辑快捷按钮」弹框（与新建同表单，回填名称、目标文字或模板图与匹配参数、自动收起），保存后原地替换、顺序不变；弹框左下「删除」需二次确认后移除该按钮（图像按钮会一并清理其模板图文件）
- **编辑态长按拖动**：长按后上下拖动子按钮可实时调整顺序（始终位于 `[+]` 下方；长按原地松手不再触发编辑）

**动作类型**：支持「文本匹配」「图像识别」「坐标点击」三种。

- **图像识别**：点击时由无障碍 `takeScreenshot` 截屏（**仅 Android 11+**），用纯 Kotlin 归一化互相关（NCC）在截屏中滑窗匹配模板图，命中后取中心坐标 `dispatchGesture` 点击；未找到可按参数重试。匹配采用「粗扫 + 逐级精扫」并在工作线程执行，不阻塞悬浮窗；截屏前会隐藏悬浮窗与当前配置弹框（两者均置为不可触摸，弹框同时不可聚焦），避免它们进入截图或吞掉触摸。
- **坐标点击**：新建/编辑弹框中手动填写屏幕像素坐标 X/Y；也可点「屏幕取点」——屏幕覆盖半透明置灰 + 网格帘（能看到下层应用），点选任意位置即自动回填坐标，触摸全部由拾取浮层消费，不会触发下层应用点击。执行时直接在配置坐标 `dispatchGesture` 点击。

**新建 / 编辑弹框的结构**（与主页共用同一套 token 与组件）：

- 动作类型用**分段单选**切换（文本 / 图像 / 坐标），与主页「连点器 / 代点器」同款控件；下方一行灰字说明当前类型含义
- 类型相关配置装进**带描边的卡片**，与主页「分区 + 卡片」层次一致：文本 → 「目标文字」输入框；图像 → 「模板图片」（缩略图占位框 + 屏幕截图 / 从相册选 + 可折叠的高级匹配参数）；坐标 → X / Y 输入框 + 实心「屏幕取点」按钮
- 「点击后自动收起悬浮窗」为整行可点的勾选项，与主页勾选行同款
- 内容超出弹框高度时由系统对话框滚动，滚到下方后可继续操作高级参数、勾选项与「新建 / 保存」按钮

**截图 / 选图期间的显示与返回**：
- 点「屏幕截图」或「从相册选」时，配置弹框与悬浮窗会先整体隐藏（均置为不可触摸、弹框不可聚焦），避免遮挡系统相册或被截进模板图；截图从「隐藏」一直保持到框选结束，确定、系统返回键取消、相册返回后自动恢复弹框与悬浮窗。
- 截图框选页与「屏幕取点」页不提供取消按钮，按系统返回键即退出该操作并回到「新建/编辑快捷按钮」弹框；相册选图页、相册裁剪页按返回键同样回到该弹框（不会关闭弹框）。

**图像识别配置**（新建/编辑弹框内，选「图像识别」后展开）：
- 模板图来源：**屏幕截图**（截当前屏 → 全屏置灰+网格 → 框内保留原色、单指拖动、双指缩放选框 → 确定裁出区域）或 **从相册选**（系统 Photo Picker 选图后用同一选框 UI 裁剪）；已选图显示缩略图，点击缩略图可重选；
- **裁剪比例**：底部比例条支持 **自由 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16 / 自定义 W:H**，默认「自由」。切换比例时以选框中心为锚点、保持面积不变地调整；锁定后单指拖动只移动选框，双指缩放只改变尺寸、比例保持不变，选框始终限制在图片范围内；
- 高级匹配参数：相似度阈值（默认 0.85）、降采样倍率（1~4，默认 2）、匹配区域（全屏 / 仅上次框选区域）、灰度匹配、未找到重试次数与间隔；
- 模板图存于应用私有目录 `filesDir/images/`，随脚本保存/加载，删除脚本或更换图片时清理旧文件。

**各控件行为**：

| 控件 | 行为 |
| --- | --- |
| [+] | 弹出「新建快捷按钮」表单：按钮名称、动作类型分段开关（文本 / 图像 / 坐标）、按类型展开的描边卡片配置（目标文字 / 模板图与匹配参数 / X·Y 坐标与屏幕取点）、自动收起勾选 |
| 脚本管理 | 打开「脚本管理」：保存当前按钮为命名脚本、加载、重命名、删除 |
| 透明度 | 打开滑块弹框，拖动时悬浮窗实时变化；拖动期间弹框与遮罩隐藏，进行条（20% 不透明度）显示在被拖动滑块的原位置；「确定」保存并在下次启动时恢复，「取消」/返回键恢复原值 |
| 关闭（X） | 关闭悬浮窗服务；有未保存按钮时先询问「保存并关闭 / 不保存关闭 / 取消」，未命名列表会先要求输入脚本名 |

> 子按钮的修改与删除统一在「编辑快捷按钮」弹框内完成（编辑态点击子按钮打开），悬浮窗不再提供 `[-]` 删除按钮。编辑弹框底部为「删除（红字）/ 取消 / 保存」三键，删除会再弹一次红色确认框。

> 两个模式的脚本加载都会先做覆盖确认：代点器在「脚本管理」、连点器在「悬浮窗设置」；连点器加载前会先停止连点。

> 连点器与代点器的全部弹框（新建 / 编辑按钮、脚本管理、透明度、关闭确认、全局设置、点击点设置、自定义裁剪比例）共用同一套弹框外框与按钮行，标题、分隔线、按钮位置完全一致。

### 3.8 统一视觉规范（设计系统）

页面与弹框共用一套 token 与通用组件，源码位于 `core/theme` 与 `core/components`。

**配色（`core/theme/Color.kt`）**：

- 品牌主色为「钢青 Teal-Steel」：浅色 `#0F6E7D`，深色 `#5AD1E0`；**显式禁用 Material3 动态取色**，保证跨设备观感一致
- 中性色与主色同 hue 家族（低饱和青灰），表面层级靠亮度差划分：`background` < `surfaceContainerLow` < `surfaceContainer` < `surfaceContainerHigh` < `surfaceContainerHighest`
- 卡片为 `surface`（浅色下即白色）+ `outlineVariant` 细描边；深色模式 `surface` 与 `background` 有明确亮度差，卡片不再糊成一片
- `success` / `warning` / `primaryPressed` 由 `AppSemanticColors` 承载（Material3 ColorScheme 无对应槽位），通过 `AppTheme.colors` 取用

**排版（`core/theme/Type.kt`）**：

| 层级 | 字号 / 字重 | 用途 |
| --- | --- | --- |
| headlineSmall | 24sp SemiBold | 页面主标题 |
| titleLarge / titleMedium / titleSmall | 20 / 17 / 15sp SemiBold | 区块标题、卡片标题 |
| bodyLarge / bodyMedium / bodySmall | 16 / 15 / 13sp | 正文、列表项、辅助说明 |
| labelLarge / labelMedium / labelSmall | 15 / 14 / 12sp | 按钮文字、**表单字段标签**、徽标 |

**间距（`core/theme/Dimens.kt`）**：

- 基础阶梯 4 / 8 / 12 / 16 / 24 / 32
- 语义间距：`screenVMargin`（页面上下留白）、`sectionGap`（分区之间）、`blockGap`（分区内块之间）、`fieldGap`（字段标签与输入框之间）、`cardPaddingLg`、`dialogHPadding` / `dialogVPadding`（弹框内边距）
- 滑块尺寸：`sliderTrackHeight`（8dp 胶囊轨道）、`sliderThumbSize`（24dp 圆形滑钮）、`sliderThumbStroke`（2.5dp 描边）、`sliderThumbShadowIdle` / `sliderThumbShadowActive`（3dp / 8dp 投影）

**通用组件（`core/components`）**：

| 组件 | 说明 |
| --- | --- |
| `AppButton` | Filled / Outlined / Text / Danger / Success 五变体，含默认 / 按下 / 禁用 / 加载四态；Outlined 为 `surface` 底 + `outlineVariant` 描边 |
| `AppCard` | `surface` 底 + 可选细描边，不叠阴影；可点击时带 ripple |
| `AppText` | `AppTitle` / `AppSectionTitle` / `AppBodyText` / `AppCaption` / `AppFieldLabel`，全部走 `MaterialTheme.typography` |
| `AppTextField` | 外观走 token；**内核保留原生 `EditText`**（overlay 弹框软键盘硬约束） |
| `AppSegmentedControl` | 分段单选（模式切换、动作类型），轨道 `surfaceContainer` 底 + 细描边；圆角用 `background(color, shape)` 绘制而非 `clip`，保证整段矩形可点（圆角处不留死区） |
| `AppSelection` | `AppRadioButtonRow` / `AppCheckboxRow`，整行可点，触控高度 ≥ 48dp |
| `AppBadge` | 状态徽标（Primary / Success / Warning / Neutral 四种色调），用于权限与运行状态；同文件另提供 `AppPillButton`——与徽标同尺寸的紧凑胶囊按钮 |
| `AppEmptyState` | 列表无内容时的统一占位 |
| `AppScriptList` | 命名脚本列表（连点器 / 代点器共用）：脚本名点击加载，右侧「改名 / 删除」，空列表交给 `AppEmptyState`；内容超高时内部滚动 |
| `AppOpacityDialog` | 透明度弹框内容（两个模式共用）：说明文案 + 一或两根滑块 + 百分比；连点器额外传入 `onPointAlphaChange` 显示「点击 / 滑动点位」滑块。拖动状态与滑块自身的屏幕矩形经 `onDraggingChange` 一并上报，由宿主隐藏弹框并把预览条放回这根滑块原来的位置 |
| `AppSlider` | 统一滑块：胶囊轨道（未激活段 `surfaceContainerHigh` 底 + `outlineVariant` 细描边，激活段 `primary`）+ 圆形滑钮（`surface` 底 + `primary` 描边 + 投影，拖动时底色转 `primaryContainer`、投影加深）；激活段右端与滑钮圆心严格对齐，交互沿用 Material3 Slider（点按跳转、拖动改值、无障碍语义），`interactionSource` 透传供调用方监听拖动 |

| `AppDialog` | **全项目弹框的唯一外框**：`AppDialogPanel`（标题区 → 1dp 分隔线 → 可滚动正文 → 1dp 分隔线 → 按钮区，圆角 20dp + `surface` 底，整体不超屏高 72%）、`AppDialogActions`（取消在左 / 主操作在右，可插 `leading` 弱化或危险操作）、`AppConfirmMessage`（确认框正文） |

**统一弹框外观**（除主页外，所有页面与弹框共用同一套外壳）：

- 外框自绘圆角与底色，平台对话框面板底已剥离，不会出现「双层框」；标题、说明、正文、按钮的排版与间距由 `AppDialogPanel` 统一给出
- 按钮行统一为「取消（白底描边）在左 / 主操作（品牌实心）在右」，危险操作主按钮换成红色实心，弱化操作（如「删除」）用红色文字
- 正文超高时在正文区内部滚动，标题与按钮始终可见（高度上限为屏高 72%）

**悬浮窗与原生浮层的统一视觉**：

- 连点器与代点器的悬浮窗按钮共用 `FloatingSquareButton`：40dp 见方、12dp 圆角、品牌实心底、白色图标、4dp 轻投影，按下加深、禁用半透明
- 截图框选页、相册裁剪页、坐标拾取浮层是原生 View，读不到 Compose 主题，故用 `OverlayViews` 提供同款按钮（12dp 圆角、品牌实心或半透明描边）与底部操作栏底色（半透明黑 + 1dp 分隔线），色值统一取 `OverlayPalette`
- 全面屏适配：铺满整屏的原生浮层与页面（截图框选页、相册裁剪页）底部操作栏统一按导航栏高度上移，判据是「操作栏底边是否触到屏幕底边」——触到才抬，窗口本身已避让导航栏时不重复留白（`core/ui/SystemBarInsets.kt`）

**XML 侧同步规则**：`res/values/colors.xml` 与 `res/values-night/colors.xml` 与 `Color.kt` 同源，**改色必须两处同步**且浅 / 深两份键对称；主题状态栏与页面背景同色（浅色用深色图标、深色用浅色图标）。

## 4. 数据持久化

**连点器（命名脚本）**：

- 命名脚本以 JSON 数组存入 SharedPreferences（文件 `clicker_script_config.xml`，键 `scripts`），每项含脚本名与点位列表；点位字段包括 ID、坐标、类型、点击位置、延迟、触摸时长、重复次数、随机距离、滑动对关联（`pairId` / `isStart` / 终点坐标）等
- 加载脚本时先停止连点，再清除现有点位并按保存顺序重建视图、管道与配对关系
- 悬浮窗透明度存于同一 SharedPreferences 的 `window_alpha` 键（0.2~1，默认 1），点击 / 滑动点位透明度存于 `point_alpha` 键（同范围），与代点器的同名键互相独立
- 旧版本的单份点位文件 `/data/data/包名/files/click_points.json` 会在首次读取脚本列表时迁移为「默认脚本」，并写入 `legacy_migrated` 标记，只迁移一次（之后删空脚本也不会重新导入）

**代点器（脚本）**：

- 命名脚本以 JSON 数组存入 SharedPreferences（文件 `quick_click_config.xml`，键 `scripts`），每项含脚本名与其子按钮配置：
  - 公共字段：名称、类型（`text` / `image` / `coord`）、目标文字、坐标 X/Y、自动收起；
  - 图像识别字段：模板图文件名、相似度阈值、降采样倍率、匹配区域（`full` / `last`）、灰度匹配、重试次数与间隔、截图框选区域 `imageRegionRect`（`"left,top,right,bottom"`，用于「仅上次框选区域」匹配）；
  - 模板图本身的宽高比不单独存储，裁剪结果已经是按所选比例裁好的 PNG。
- 图像识别的模板图为 PNG，存于应用私有目录 `filesDir/images/`，脚本 JSON 中仅记录文件名；删除脚本、删除图像按钮或更换图片时会清理对应的旧图片文件
- 悬浮窗上正在编辑的按钮列表仅存在于内存，**不会自动持久化**；只有「保存当前按钮 / 另存为」命名后的脚本才会落盘，并可在「脚本管理」中再次加载
- 点击手势时长（默认 80ms）、防抖间隔（默认 500ms）与悬浮窗不透明度（键 `window_alpha`，范围 0.2~1，默认 1）同样存在该 SharedPreferences 中

## 5. 非功能性需求

- 兼容 Android 7.0（API 24）及以上
- 悬浮窗默认吸附左侧边缘，可拖动
- 设置对话框等采用 `TYPE_APPLICATION_OVERLAY`，确保在其他应用之上显示
- 前台服务运行时显示通知，提供停止按钮
- 两个悬浮窗服务用 `foregroundServiceType="dataSync"`，并在 manifest 声明 `FOREGROUND_SERVICE_DATA_SYNC` 类型权限；Android 13+ 运行时申请 `POST_NOTIFICATIONS`，被拒绝也不影响悬浮窗运行（仅通知栏入口不可见）
- Android 15+ 的 `dataSync` 时长上限由 `Service.onTimeout(startId, fgsType)` 接管：主动 `stopSelf()` 优雅停止，避免系统以 `RemoteServiceException` 结束进程
- 主界面、悬浮窗与弹框使用 Jetpack Compose，经 `ComposeView` 承载；Service 内用 `ServiceComposeHost` 补齐 Compose 所需的生命周期宿主，带输入框的 `TYPE_APPLICATION_OVERLAY` 弹框需清除 `FLAG_ALT_FOCUSABLE_IM` 才能弹出软键盘
- 两个悬浮窗服务的弹框统一由 `ServiceDialogs.show()` 承载（平台 `AlertDialog` + 透明窗底 + `TYPE_APPLICATION_OVERLAY`），弹框内容统一套 `AppDialogPanel` 外框，两个悬浮窗的按钮统一用 `FloatingSquareButton`
- 代点器的截图框选页、裁剪比例条、坐标拾取浮层使用原生 View 承载（全屏 `TYPE_APPLICATION_OVERLAY` 场景下按键与窗口焦点更可控）
- 连点器在应用从最近任务划掉时自动停止服务并移除悬浮窗
